# Система учета заказов кафе

## Назначение

Приложение предназначено для учета и обработки заказов кафе.  
На первом этапе реализуется консольный сценарий, который позволяет:
- зафиксировать заказ;
- определить блюдо и его стоимость;
- указать ответственного сотрудника;
- проверить текущий статус заказа.

## Целевая аудитория

- администраторы кафе;
- официанты;
- менеджеры смены;
- сотрудники кухни, которым необходимо видеть статус заказа.

## Предметная область

Общественное питание: учет заказов в кафе.  
Заказ связан с блюдом, сотрудником и статусом.  
В дальнейшем система будет хранить данные в базе данных, разграничивать доступ пользователей и предоставлять API.

## Основные сущности

- **Заказ** — идентификатор, дата, сумма, текущий статус.
- **Блюдо** — название, цена, категория.
- **Сотрудник** — имя, должность, идентификатор.
- **Статус** — состояние заказа: новый, готовится, готов, завершен, отменен.

## Основные функции

- расчет стоимости заказа по цене блюда и количеству;
- определение и расшифровка статуса заказа;
- проверка возможности отмены заказа в зависимости от статуса;
- вывод информации о заказе с данными сотрудника и итоговой суммой.

## План развития

На следующих этапах планируется:
- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
